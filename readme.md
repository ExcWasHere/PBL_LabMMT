# <h1 align="center">Portal Showcase – Lab Multimedia & Mobile Tech</h1>

Platform web interaktif untuk menampilkan profil laboratorium, showcase proyek digital, publikasi kegiatan, serta dashboard admin untuk pengelolaan konten.  
Dikembangkan sebagai bagian dari **Project Based Learning Semester 3**

🌐 **Deployed on:** [https://pbl-lab-mmt.vercel.app/](https://pbl-lab-mmt.vercel.app/)

---

## Tentang Project

Portal Showcase ini membantu Laboratorium Multimedia & Mobile Tech dalam menampilkan:

- Identitas dan profil lab  
- Showcase proyek digital mahasiswa (UI/UX, AR/VR, Game, Mobile App, dll.)  
- Berita, event, dan publikasi kegiatan  
- Galeri foto/video  
- Dashboard admin untuk pengelolaan konten

---

## Fitur-Fitur Utama

### 🌐 Public Website
- Halaman Beranda  
- Profil Lab: visi, misi, struktur organisasi  
- Katalog Proyek dengan filter  
- Halaman Detail Proyek  
- Daftar Berita & Kegiatan  
- Detail Artikel  
- Galeri Foto & Video  

### 🛠 Dashboard Admin (CMS)
- Login Admin (JWT Auth)  
- CRUD Proyek  
- CRUD Berita & Kegiatan  
- CRUD Galeri  
- Upload media  
- Role management dasar  
- Ringkasan Statistik  
- Filter sponsorship & oprec

---

## Tech Stack

### Frontend
- React Router v7  
- Tailwind CSS  

### Backend
- NestJS  
- PostgreSQL  
- TypeORM 

### Deployment
- Frontend: Vercel  
- Backend: Vercel
- Database: Supabase  

---

## Installation

### 🔵 Frontend (React Router v7)

1. Clone & install dependencies:
```bash
cd frontend
npm install
npm run dev
```

---

### 🔴 Backend (NestJS)

1. Install backend:
```bash
cd backend
npm install
npm run start:dev
```
